HOW TO RUN

1. Open a terminal in this folder.
2. Make sure Python 3 is installed.
3. Install NumPy:

   python -m pip install numpy

4. Run everything:

   python run_all.py

5. Open results_auto.txt.
6. Copy the empirical values into completed_worksheet_template.txt.
7. Fill in your name, ID, date, laptop model, CPU/cache/RAM information.

IMPORTANT:
The worksheet explicitly requires empirical measurements from the student's own
machine. Do not replace the measured values with theoretical or invented numbers.
